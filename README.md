# 早晚打卡

一个在手机和电脑浏览器上使用的个人习惯打卡页。支持早晚两套习惯、逐项打卡、补品和小记，以及按周、月、年查看习惯足迹。

[打开早晚打卡](https://shanec7825.github.io/daily-ritual/)

记录保存在当前浏览器和站点地址的本地存储中。切换设备、浏览器或从局域网地址换到 GitHub Pages 时，原地址上的记录仍保存在原处。

## 本地运行

打开 `index.html`，或在项目目录启动本地静态服务器。

```sh
python -m http.server 8080 --bind 127.0.0.1
```

在浏览器访问 `http://127.0.0.1:8080/`。运行 `node verify.cjs` 可检查打卡顺序、日期和历史记录逻辑。第三方依赖及对应许可证在 `vendor/`。
